# Hidden Gems

A video series about unique, under-hyped open AI models. We test each one hands-on on a gaming laptop and give an
honest verdict. Each episode folder has its own README with the setup, the exact scripts we ran, the inputs and our raw
results, so you can check our numbers or run the same test on your own GPU.

| # | Model | What it does | Folder |
|---|---|---|---|
| 1 | [Idol](https://huggingface.co/speridlabs/idol) by Speridlabs | one image → 3D Gaussian splat | [`01-idol/`](01-idol/) |

**Our test machine:** gaming laptop with an RTX 3070 Ti Laptop GPU (8 GB), Intel Core i7-12650H, Windows 11 + WSL2 (Ubuntu).
